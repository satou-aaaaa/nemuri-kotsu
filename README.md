# 眠りのコツ（nemuri-kotsu）

夜や朝の過ごし方を2つ比べて、よく眠れるほうを選ぶ1日5問の学習ゲーム。正解したら「何のためのコツ？」も選ぶ。

遊ぶ: <https://satou-aaaaa.github.io/nemuri-kotsu/>

- 中身は厚生労働省「健康づくりのための睡眠ガイド 2023」本文で確かめたことだけ（<https://www.mhlw.go.jp/content/001305530.pdf>）。
- このゲームは医療の助言や、公式の情報の代わりではありません。眠れない日が長く続くときは医師に相談してください。
- 場面と人はすべて架空です。記録は遊ぶ人のブラウザだけに残り、外へ送りません。

作業の決まりは [AGENTS.md](AGENTS.md)。
